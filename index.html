Alur Komponen & Fungsi Sistem
1

Multi-Sensor (Tanah, Air & Gempa)

Mengambil data fisik lingkungan secara real-time meliputi pergerakan/kelembapan tanah (longsor), ketinggian air (banjir), serta getaran seismik (gempa bumi).

2

Mikrokontroler (Arduino)

Membaca sinyal mentah dari ketiga sensor, mengolahnya menjadi data digital terstruktur, dan menyiapkannya untuk dikirimkan.

3

Modul LoRa (Long Range)

Mengirimkan data dari lokasi sensor di alam terpencil menuju pos pemantau dengan daya rendah dan jangkauan jarak jauh.

4

Gateway

Menerima sinyal gelombang radio LoRa dari lapangan dan menerjemahkannya agar siap disalurkan ke sistem jaringan penerusan.

5

Parabola (Stasiun Pemancar)

Memancarkan gelombang sinyal data berfrekuensi tinggi secara nirkabel menembus atmosfer menuju satelit dari daerah terpencil.

6

Satelit Komunikasi

Menerima pancaran sinyal dari parabola di bumi dan memantulkannya kembali ke stasiun penerima jaringan global secara instan.

7

Internet Cloud

Menyediakan jalur penghubung berbasis jaringan global untuk mentransfer paket data dari stasiun bumi menuju server utama.

8

Server

Menyimpan, mengelola, dan memproses database data masuk serta menjalankan logika peringatan otomatis jika kondisi bahaya.

9

Aplikasi Web

Menampilkan antarmuka visual berupa dashboard, grafik tren, peta lokasi, dan status siaga bencana kepada publik.

10

Pengguna (User)

Memantau informasi kebencanaan secara real-time via web/HP dan menerima peringatan dini untuk tindakan evakuasi.
